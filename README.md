# Finaly step (Куприянов Артемий)
## Моя идея для проекта:
#### телеграмм бот который может отвечать на вопросы о глобальном потеплении и о том как его предотвратить, а также в нём есть мини игра и он может выдавать рандомный факт этот бот поможет больше узнать о потеплении.
##### В этом тг боте есть функция помощи help она покажет все команды которые есть в боте восномном это вопросы, но также есть и миги игра ответь за 5 секунд бот задаст тебе вопрос например "Назови 3 причины глобального потепления 🌍" и ты должен будешь на него ответить за 5 секунд ещё если использовать команду random_advice то бот выдаст тебе один из интересных фактов этот бот называется global_warming-question
